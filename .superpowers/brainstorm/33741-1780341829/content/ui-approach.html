How closely do we match Paint's ribbon UI?

egui (the GUI framework ArsPaint uses) is immediate-mode — it doesn't have a ribbon widget. We have to build or fake it. Three approaches:

A

Build a real ribbon — Home / View tabs

Faithful layout: tab bar, grouped sections (Clipboard · Image · Tools · Shapes · Colors), icons + labels, shape gallery with scroll. Looks like modern Paint. More work up front, but the muscle memory will transfer directly.

B

Two-row toolbar — same tools, simpler layout

All the same tools and groups as modern Paint, but laid out as a compact two-row horizontal toolbar (like ArsPaint has now, just expanded). No tab switching. Tools work identically — just less chrome. Gets us working faster, and we can skin it later.

Good middle ground: behavior-faithful, UI-pragmatic. egui handles this naturally without custom widget work.
