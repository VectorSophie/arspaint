Which MS Paint era are we targeting?

The UI layout and available tools differ significantly between versions. This shapes the whole Phase A scope.

A

Classic — Windows 95 / 98 / XP

Menu bar (File Edit View Image Colors Help) + vertical floating toolbox on the left + color palette bar at the bottom. Tools are small icons in two columns. Simple and iconic — this is the version most people picture when they say "MS Paint."

B

Modern-ish — Windows 7 / 10 ribbon

Ribbon UI at the top (Home / View tabs) with tools organized in groups: Clipboard, Image, Tools, Shapes, Colors. Feels more like a modern app. Larger touch-friendly hit targets. This is what most people under ~25 know as Paint.

C

XP spirit, our own layout

Keep the classic tool set (all XP-era tools) but lay them out in a way that feels natural in egui — maybe a horizontal toolbar at top like the current ArsPaint, no ribbon. Functionally faithful, but we don't try to pixel-match the Win95 chrome.

Best fit for egui's immediate-mode layout. Easier to build. Focuses effort on tool behavior rather than UI chrome.
